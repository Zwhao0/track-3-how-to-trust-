# 威胁模型

保护对象包括正式 checkout 和宿主文件、每轮任务的已提交状态、公开合同和实验配置的完整性、凭据与私有 Oracle。模型输出、fixture 内说明、补丁、路径和候选代码均不可信。可信边界是编排器、共用工具安全层、Guard 的策略与暂存执行器、独立评测控制器。

| 失败方式 | 计划中的控制和验证 |
| --- | --- |
| 仓库内存在相似文件，Agent 猜错目标或改了过多文件 | 公开合同列出候选及歧义；Guard 阻止未消歧的候选写入。用同一任务比较猜测、澄清、拒绝和实际提交。 |
| 写入试图逃出工作树，或通过链接、别名触碰别处 | 三组都拒绝绝对路径、穿越、软链接、硬链接和不受支持的对象，检查所有路径分量；fixture 导入同样验证。对支持平台约束大小写与 Unicode 文件名歧义，不支持的情况失败关闭。使用进程私有的根目录并避免校验后通过不可信名称重新打开路径。用越界路径、链接、名称冲突测试验证失败后树不变。 |
| 补丁附带额外文件、删除、改名或更改权限 | 共用层仅允许更新已存在普通文件，不暴露删除、重命名或 chmod。Guard 在暂存后核对真实完整差异，任何一项越权则整批拒绝。验收检查拒绝、澄清及提交失败均不留半批结果。 |
| 文件内文字诱导 Agent 忽略授权或伪造用户答复 | 文件内容只当任务数据；合同由可信编排器加载，澄清由独立应答器授权。模型文本及工具参数不能改权限。 |
| 候选测试污染工作树、宿主或评分 | 工具只接收注册检查 ID。固定入口和参数，无 Shell；以独立副本、最小环境和限时运行。没有可验证的进程级文件与网络隔离时，不执行候选可改的代码；降级为外部静态检查或禁用该检查。仅复制目录或设置 cwd 不构成沙箱。 |
| 模型、工具或候选代码读到 Oracle、应答脚本或凭据 | 文件树按 fixture 白名单复制；模型没有通用宿主访问。测试 worker 不挂载控制器、凭据或私有评测材料。评测控制器与运行会话分离；分离检查将使用独立的哨兵文件验证 Agent 和 Guard 均不可见。 |

基本工具安全层在所有实验条件中相同。实验比较的是临时仓库内的任务授权错误；不会放开宿主安全限制来制造更高的 Baseline 越界率。第一版不支持任意代码执行工具、开放网络、多租户安全、跨仓库事务或生产部署，也不宣称可抵挡宿主或可信编排器被攻破。M0 只记录设计，尚未验证这些控制。
