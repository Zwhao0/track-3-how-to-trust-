# 课堂演示点击顺序

先按[中文快速开始](QUICKSTART_CN.md)运行 `demo verify` 和 `demo serve`。

| 时间 | 操作 | 讲解 |
| --- | --- | --- |
| 0:00–0:40 | 打开「写入对照」，定位 `tests/notes.txt` | 两组收到相同的受控脚本。B0 接受了保护文件写入，B2 拒绝，且授权修改在两边都完成。 |
| 0:40–1:10 | 打开「受控验证」 | 展示合法双文件修改，再看先写后问的情境。B0 留下额外改动，B2 等授权更新后只写授权目标。 |
| 1:10–1:55 | 打开「澄清回放」，依次点击暂停、询问、答复和授权更新 | 这条开发记录来自真实 Codex，答复由脚本提供。最后再打开文件差异。 |
| 1:55–2:40 | 打开「正式结果」 | 三组都主动澄清，72 次均安全完成，越界尝试为零，拦截率无法估计。B2 在受控违规请求中的行为有单独记录。 |

录屏可重复同样的本地归档操作。浏览器无法使用时，终端运行 `PYTHONPATH=src python3 -m scopeguard demo replay --case run-ipwb50oo`。
